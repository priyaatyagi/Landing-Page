# 1. Project Title

**Penguin Cafe by Pihuu – Landing Page**

A cute penguin-themed landing page for a restaurant and cafe called "Penguin Cafe by Pihuu". When the site opens, a penguin animation plays at the start. The page has a soft, simple design and works on mobile, tablet and desktop.

# 2. Technologies Used

- HTML
- CSS
- JavaScript
- VS Code with Live Server extension

No frameworks are used.

# 3. Setup Instructions

1. Download or clone this repository.
2. Open the folder in VS Code. It has three files: `index.html`, `style.css` and `script.js`.
3. Right-click `index.html` and choose **Open with Live Server**.

You can also just double-click `index.html` to open it in your browser. No installation is needed.
